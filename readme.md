# FIXTURE_NT_ESP32 治具控制系统 V1.0.0

这是一套基于 **ESP32-S3** 与 **FreeRTOS** 构建的高性能治具测试/充放电控制系统。系统集成了高精度 ADC 数据采集、极速硬件保护、优雅的状态机 LED 指示、以及防死机的局域网 Web OTA 升级功能。

---

## 💻 硬件架构

* **主控 MCU**：ESP32-S3 (芯片型号：ESP32-S3FH4R2，4MB Flash，OPI PSRAM)
* **ADC 采样**：ADS1115 (16-bit 高精度独立 ADC，I2C 地址 `0x48`)
* **电源与充电 IC**：
  * **SC8726A (升降压与使能控制)**：负责核心供电输出。单片机可通过直接控制其 **CE（Chip Enable）引脚**，在发生过流或过压时实现微秒级的物理断电保护。
  * **专用锂电池充电芯片**：单片机并不直接干预充电的恒流/恒压底层过程，而是通过监听充电芯片输出的 `STATE_CHRG` (充电中) 和 `STATE_OK` (已充满) 两个硬件引脚，来同步软件系统状态，并驱动 LED 跑马灯动画。
* **存储机制**：NVS (Non-Volatile Storage)，保证断电参数不丢失
* **LED 指示灯**：四挡电量跑马灯 (25%, 50%, 75%, 100%) + 四挡状态灯 (UC, OK, OC, START)

## ⚙️ 软件架构与 FreeRTOS 任务说明

系统严格遵循模块化与高内聚设计，所有功能均被拆分为独立的后台 RTOS 任务，互不阻塞：

| 任务名称 | 周期/触发方式 | 核心职责 |
| :--- | :--- | :--- |
| **`Task_ADC`** | 15ms / 200ms | **[极高优先级]** 负责极速读取 ADS1115 数据并进行一阶 IIR 滤波。一旦发现过流或过压，越级通知电源任务瞬间切断输出。空闲时自动降频至 200ms 采样以降低功耗。 |
| **`Task_System`** | 100ms 轮询 | **[核心逻辑]** 负责整合数据、判断电池电量区间 (`BAT_25`~`BAT_100`)、监控硬件充电状态引脚 (`STATE_CHRG`, `STATE_OK`)，以及检测长按按键 (触发 WiFi)。 |
| **`Task_LED`** | 500ms 轮询 | **[UI 渲染]** 根据全局状态机变量渲染指示灯。包含：充电流水动画、放电常亮显示、过流过压故障闪烁报警，以及 WiFi 启动时的顺序递进点亮动画。 |
| **`Task_Monitor`** | 500ms 轮询 | **[终端交互]** 监听并解析串口发来的各种参数修改指令。定时打印系统当前的实时状态信息供调试查看。当参数改变时触发 NVS 持久化保存。 |
| **`Task_Power`** | 事件驱动 | 专门负责底层硬件的使能与切断。接收来自 ADC 任务的紧急断电通知，执行 OCP/OVP 断电保护操作。 |
| **`Task_Wireless`** | 按键触发激活 | 仅在长按 BOOT 键 3 秒后激活。负责建立 WiFi AP 热点，启动 Web 服务器，并接管处理 `.bin` 固件的 OTA 极速安全烧录逻辑。 |
| **`Task_RST`** | 指令触发激活 | 负责外部设备的复位控制引脚（GPIO14）。触发后按照设定的时序拉高、再拉低引脚。一次性任务，执行完后自动销毁以释放内存。 |

## 📡 WiFi OTA 升级指南

为了保证系统的绝对安全与轻量，OTA 功能默认处于**关闭**状态。

1. **激活 WiFi**：长按板子上的 **BOOT 键（GPIO0）持续 3 秒**。此时前四个状态灯会呈现递进点亮动画，代表热点已启动。
2. **连接热点**：
   * **WiFi 名称 (SSID)**：`FIXTURE_01_OTA` *(注：FIXTURE_01 为设备名，可通过串口自定义)*
   * **WiFi 密码**：`12345678`
3. **上传固件**：
   * 打开手机或电脑的浏览器，访问网址：**`http://192.168.4.1/`**
   * 在极其简约的暗黑风格网页中，选择编译好的 `.bin` 固件文件，点击上传。
   * 烧录期间，串口会静默，仅网页显示上传进度。烧录完成后系统会自动重启并应用新固件。

## ⌨️ 串口指令与动态参数配置

所有的配置参数都会被保存在单片机的 NVS Flash 中，断电**永不丢失**。
**指令格式**：无需任何前缀，直接通过串口（波特率 `115200`）发送 `[参数名] [数值]`，中间带一个空格即可。

### 1. 保护与电气阈值调节
* `IMAX 2.5`：将过流保护 (OCP) 阈值设为 2.5A。
* `IMIN 0.1`：将欠流判定 (UCP) 阈值设为 0.1A。
* `ISTART 0.5`：将启动判定阈值设为 0.5A。
* `VOUT 5.0`：设定目标输出电压为 5.0V。（系统会自动将极速过压保护阈值设为 5.0 + 0.4 = 5.4V）。
* `DELAY 5000`：设置启动状态的自锁延时时间（毫秒），例如 5000 代表 5 秒。

### 2. RST 复位时序参数
* `RSTON_TIME 5000`：设置复位引脚拉高持续的时间（毫秒）。
* `RSTOFF_TIME 2000`：设置复位引脚拉高结束后，再次拉低持续的时间（毫秒）。
* `OPEN_RST`：**开启**外部 RST 引脚复位功能（并执行一次时序）。
* `CLOSE_RST`：**关闭**外部 RST 引脚复位功能。

### 3. 系统维护与调试指令
* `NAME FIXTURE_02`：修改设备名称为 `FIXTURE_02`。修改后，下次开启 WiFi 时的热点名称将同步变为 `FIXTURE_02_OTA`。
* `CALIB_I`：**一键电流校准**。在未接任何负载时发送此命令，系统会自动采集当前的本底电流底噪，并将其作为偏移量（I_Offset）保存入 NVS，彻底消除空载时的电流漂移。
* `REBOOT`：立即重启单片机。
* `FORMAT_NVS`：**恢复出厂设置**。格式化 NVS 分区并重启，所有手动设置的参数将被清空，恢复为代码默认值。
